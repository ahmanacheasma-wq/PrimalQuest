# # 🌿 PrimalQuest

## Description

**PrimalQuest** est un jeu vidéo 2D développé en Python avec la bibliothèque Pygame, inspiré de l'univers préhistorique.

Le joueur évolue dans un environnement naturel rappelant l'âge de pierre, entouré d'arbres, de végétation et de créatures dangereuses.

L'objectif principal est de survivre en affrontant les monstres, en évitant leurs attaques et en accumulant des points.

Le jeu combine **action, aventure et survie** dans une ambiance préhistorique.

## Fonctionnalités principales

- Déplacement et contrôle du personnage.
- Présence de monstres et d'ennemis.
- Système d'attaque et de combat.
- Gestion des collisions.
- Système de score.
- Environnement graphique inspiré de la préhistoire.

## Technologies utilisées

- **Langage :** Python
- **Bibliothèque :** Pygame
- **Environnement de développement :** Visual Studio Code

## Développement

PrimalQuest est un projet évolutif visant à améliorer progressivement les mécanismes de jeu, les interactions avec les ennemis et l'expérience du joueur.
